# Jehangir — People Behind the Visit

Independent student case study of Jehangir Art Gallery, Mumbai. Visitor personas lead the study; artist perspectives, exhibition economics, field photographs and recommendations provide context.

## Run locally

Requires Node.js 24 or later.

```
npm ci
npm run dev
```

`npm test` checks the exhibition estimator and research references. `npm run build` produces the static website in `dist/`. GitHub Actions publishes the main branch to GitHub Pages.

## Evidence conventions

- Five interpretive visitor personas, not a representative segmentation survey.
- Fourteen recording sections reviewed, with overlaps and continuations acknowledged. No verified independent respondent count or mean rating is claimed.
- Anonymous relevant excerpts only; full transcripts and unrelated personal details are excluded.
- Source 14 is a separate uncertain-venue appendix, excluded from Jehangir persona evidence.
- The photographed fee notice states effective **1 July 2027**. It is not presented as current November 2026 pricing. Amounts and the unusual Gallery 1 group rate are transcribed as photographed.
- The historical five-year-wait report does not establish a guaranteed current wait.
- Original photographs were converted to WebP with metadata removed. Descriptive artwork captions are not verified artwork titles or artist attributions.
- Team names and portrait matches have not been supplied, so group and generic individual credits are used.

Artwork rights remain with their respective creators. This project is independent of the gallery.
